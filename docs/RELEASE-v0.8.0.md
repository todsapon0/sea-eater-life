# บันทึกเวอร์ชัน v0.8.0 (สร้าง 2026-11-01 โดย Claude)

**ไว้ใช้ตอนเจอบั๊กแล้วต้องย้อนกลับ/ตามหาสาเหตุ** — อ่านส่วน "จุดย้อนกลับ" และ "ของที่เพิ่ม + ไฟล์/ฟังก์ชันที่เกี่ยว" เพื่อรู้ว่าอะไรเปลี่ยนในเวอร์ชันนี้

## สถานะ
- สาขา `claude/family-build` (PR #11 draft) **ยังไม่ merge เข้า `main`** — `main` ยังเป็น v0.5.4 (commit 2e6b207) ที่เด็กเล่นอยู่ รวมเข้า main ต่อเมื่อผู้ใช้ทดสอบ iPad + เซฟเก่าแล้ว "สั่งเอง"
- ผู้ใช้ทดสอบ iPad 8 บางส่วนแล้ว (2026-11-01): ผ่าน, FPS ~37–45 ตอนสู้ 3–4 ตัว/เปิดเมนู; ยังไม่ได้ทดสอบครบรายการ B/B2/C ใน `RELEASE-CHECKLIST.md`
- ภาพ/โมเดล/ไอคอนทั้งชุดใหม่ ยังเป็นภาพคอนเซปต์ (`docs/concept/`) ไม่ได้นำเข้าเกม — เป็นงานเวอร์ชันถัดไปของโค

## จุดย้อนกลับ (ใช้ git)
- เวอร์ชันที่เด็กเล่นอยู่เดิม: commit `2e6b207` (main, v0.5.4) — ควรสร้างแท็ก `v0.5.4-stable` ที่ commit นี้ใน GitHub ก่อน merge เสมอ
- โค้ดเกมสุดท้ายของ v0.8.0: commit `82c7d18` (ดูท้ายเอกสาร)
- ถ้าบั๊กเกิดหลัง merge: `git revert -m 1 <merge-commit>` (ห้าม force push) หรือเอา `main` กลับไปชี้แท็ก `v0.5.4-stable` ผ่าน PR ย้อน
- ถ้าเจอบั๊กเฉพาะของใหม่ ให้ revert เฉพาะ commit ที่ระบุด้านล่าง (แต่ละฟีเจอร์อยู่ใน commit แยก)
- เซฟ: ฟิลด์ใหม่ทั้งหมดเป็นแบบเสริม เซฟ v0.4/v0.5 โหลดได้ (ตรวจใน `save-tools.js` + test-save-tools.cjs) ผู้เล่นควรกด "คัดลอกรหัสเซฟ" เก็บไว้ก่อนอัปเดต

## ตัวเลขสมดุลที่ผมตั้งเอง (ปรับได้ถ้ายากหรือง่ายไป)
- ตีเบาลง 10%/เลเวลที่ต่ำกว่าแมพ (ต่ำสุด 30%); โดนแรงขึ้น 8%/เลเวล (สูงสุด x2); `dmgScale` ตามระดับแมพ [1,1,1.2,1.5,1.3,1.8]
- ราชา: เลือด x6, ดาเมจ x1.6, ตัว x1.3, EXP x8, เกิดใหม่ 8 นาที (นับเฉพาะตอนอยู่แมพนั้น)
- EXP ลดเมื่อเลเวลเกิน rec+5 (10%/เลเวล ต่ำสุด 20%)
- Sea Eater x1.5, ระยะกัด x1.5, กล้องเริ่ม 31

## ปัญหาที่ยังเปิดอยู่ / รู้ว่าไม่สมบูรณ์
- แถบล่างจอบน iPad ไอคอนหน้าจอหลัก: ภาพ 3D วาดไม่ถึง (พื้นที่ระบบ) แก้โดยกลืนสีพื้น ไม่หายสนิท (ทางออก: เล่นใน Safari หรือเพิ่มไอคอนใหม่ — เซฟแยกกัน ต้องสำรองรหัสเซฟก่อน)
- เส้นเชื่อมวงแหวนในแผนที่สมุดเป็นเส้นทแยง ไม่ใช่เส้นโค้ง; ไอคอนเป็นอีโมจิ/SVG เดิม
- ราชามอนสเตอร์ใช้หน้าตาเดิม ตัวใหญ่ขึ้นเท่านั้น; แมพร่องลึกใช้มอนสเตอร์เดิม
- สัตว์เลี้ยง (พักไว้), ตัวละครที่ 4 (Tenticle Crab) ยังไม่ทำ
- ไม่เคยทดสอบแนวตั้ง (ผู้ใช้สั่งห้าม); `review.sh` มีเคสแนวตั้งบางชุด
- ตัวเลข FPS ของแมพร่องลึก/มอนสเตอร์ 5+ ตัว ยังไม่ได้วัด
