# บันทึกภาพตัวอย่าง

วันสร้าง: 2026-10-31 UTC / 2026-11-01 เวลาไทย. เครื่องมือ: OpenAI Image Generation ภายใน ChatGPT; แปลง PNG ผลลัพธ์เป็น JPEG ด้วย Pillow คุณภาพ 88 เพื่อลดขนาด โดยคงภาพต้นฉบับที่สร้างไว้ในพื้นที่เครื่องมือ ใช้ Image Generation ปรับมุมมองจากร่างที่สร้างเอง และแก้ Bloop เพื่อไม่เพิ่มจำนวนตา ภาพทั้งหมดเป็น **คอนเซปต์รอผู้ใช้เลือก** ยังไม่ใช่แอสเซ็ตเกม

| ไฟล์ | สรุป prompt / ต้นแบบรูปร่าง |
|---|---|
| `docs/concept/set1_sea_eater.jpg` | สร้างสัตว์ทะเลลึกตัวสีเทาอมม่วง ไม่มีตา ปากกลวงมีริ้ว ขาหน้าโค้ง 2 ข้างเท้าแบน หางเรียวมีครีบ; ใช้ภาพเรนเดอร์โมเดล Sea Eater ของเกมและคำบรรยายภาพที่ผู้ใช้อนุมัติเป็นแนวรูปร่าง แล้วใช้ Image Generation ปรับภาพร่างที่สร้างเองให้เห็นปล้องลำตัวชัดขึ้น; สองมุมเฉียงบนและข้าง |
| `docs/concept/set1_bloop.jpg` | ปลาวาฬทะเลลึกสีเขียวเข้ม ปากรูปไข่ฟันเล็ก ตาเล็ก 2 ข้าง ครีบอกยาว หางเรียวแฉก; ใช้ภาพเรนเดอร์โมเดล Bloop ของเกมเป็นแนวรูปร่าง โดยไม่เอา UI หรืออุปกรณ์; สองมุมเฉียงบนและข้าง |
| `docs/concept/set1_el_gran_maja.jpg` | หัวแบนกว้างทรงกระเบน ตาสีฟ้าเรียง 6 ดวง ปากวงกลมฟันละเอียดใต้หัว หางยาวเป็นปล้องปลายแหลม; ใช้ภาพเรนเดอร์โมเดล Maja ของเกมเป็นแนวรูปร่าง โดยไม่เอา UI หรืออุปกรณ์; สองมุมเฉียงบนและข้าง |

ทุก prompt กำหนดฉากทะเลลึกมืด น้ำเขียวฟ้า แสงลอดจากด้านบน ผิวหยาบสมจริง ไม่มีตัวหนังสือ โลโก้ หรือลายน้ำ และไม่ลอกตัวละคร/ภาพจากเกมอื่น ไม่เก็บภาพอ้างอิงจากภายนอกลงรีโป ภาพร่าง Sea Eater สร้างจากคำบรรยายที่บันทึกไว้และรูปร่างโมเดลเกม เพราะภาพต้นฉบับที่ผู้ใช้อนุมัติไม่ปรากฏในรีโป จึง **ยังยืนยันความตรงกับภาพอนุมัติเดิมแบบเปรียบเทียบภาพไม่ได้**; ให้ผู้ใช้ตัดสินก่อนใช้เป็นต้นแบบ

ไฟล์เป็นภาพตัวอย่างสองมุมต่อหนึ่งภาพ ไม่ใช่ texture, rig หรือโมเดล 3D; งบแอสเซ็ตเกมรวม ~15 MB ต้องวัดจากไฟล์สุดท้ายเมื่อนำไปใช้ภายหลัง
