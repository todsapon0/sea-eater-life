# บันทึกภาพตัวอย่าง

วันสร้าง: 2026-10-31 UTC / 2026-11-01 เวลาไทย. เครื่องมือ: OpenAI Image Generation ภายใน ChatGPT; แปลง PNG ผลลัพธ์เป็น JPEG ด้วย Pillow คุณภาพ 88 เพื่อลดขนาด โดยคงภาพต้นฉบับที่สร้างไว้ในพื้นที่เครื่องมือ ใช้ Image Generation ปรับมุมมองจากร่างที่สร้างเอง และแก้ Bloop เพื่อไม่เพิ่มจำนวนตา ภาพทั้งหมดเป็น **คอนเซปต์รอผู้ใช้เลือก** ยังไม่ใช่แอสเซ็ตเกม

| ไฟล์ | สรุป prompt / ต้นแบบรูปร่าง |
|---|---|
| `docs/concept/set1_sea_eater.jpg` | สร้างสัตว์ทะเลลึกตัวสีเทาอมม่วง ไม่มีตา ปากกลวงมีริ้ว ขาหน้าโค้ง 2 ข้างเท้าแบน หางเรียวมีครีบ; ใช้ภาพเรนเดอร์โมเดล Sea Eater ของเกมและคำบรรยายภาพที่ผู้ใช้อนุมัติเป็นแนวรูปร่าง แล้วใช้ Image Generation ปรับภาพร่างที่สร้างเองให้เห็นปล้องลำตัวชัดขึ้น; สองมุมเฉียงบนและข้าง |
| `docs/concept/set1_bloop.jpg` | ปลาวาฬทะเลลึกสีเขียวเข้ม ปากรูปไข่ฟันเล็ก ตาเล็ก 2 ข้าง ครีบอกยาว หางเรียวแฉก; ใช้ภาพเรนเดอร์โมเดล Bloop ของเกมเป็นแนวรูปร่าง โดยไม่เอา UI หรืออุปกรณ์; สองมุมเฉียงบนและข้าง |
| `docs/concept/set1_el_gran_maja.jpg` | หัวแบนกว้างทรงกระเบน ตาสีฟ้าเรียง 6 ดวง ปากวงกลมฟันละเอียดใต้หัว หางยาวเป็นปล้องปลายแหลม; ใช้ภาพเรนเดอร์โมเดล Maja ของเกมเป็นแนวรูปร่าง โดยไม่เอา UI หรืออุปกรณ์; สองมุมเฉียงบนและข้าง |

ทุก prompt กำหนดฉากทะเลลึกมืด น้ำเขียวฟ้า แสงลอดจากด้านบน ผิวหยาบสมจริง ไม่มีตัวหนังสือ โลโก้ หรือลายน้ำ และไม่ลอกตัวละคร/ภาพจากเกมอื่น ไม่เก็บภาพอ้างอิงจากภายนอกลงรีโป ภาพร่าง Sea Eater สร้างจากคำบรรยายที่บันทึกไว้และรูปร่างโมเดลเกม เพราะภาพต้นฉบับที่ผู้ใช้อนุมัติไม่ปรากฏในรีโป จึง **ยังยืนยันความตรงกับภาพอนุมัติเดิมแบบเปรียบเทียบภาพไม่ได้**; ให้ผู้ใช้ตัดสินก่อนใช้เป็นต้นแบบ

ไฟล์เป็นภาพตัวอย่างสองมุมต่อหนึ่งภาพ ไม่ใช่ texture, rig หรือโมเดล 3D; งบแอสเซ็ตเกมรวม ~15 MB ต้องวัดจากไฟล์สุดท้ายเมื่อนำไปใช้ภายหลัง

## ชุดที่ 2 — มอนสเตอร์ 4 แบบ

วันสร้าง 2026-11-01 UTC. เครื่องมือ OpenAI Image Generation; ใช้ภาพตัวอย่าง Sea Eater ชุด 1 ที่สร้างเองเป็นแนวแสง/โทน และภาพเรนเดอร์จากโมเดลเกมปัจจุบันแต่ละชนิดเป็นแนวรูปร่าง (ภาพเรนเดอร์อ้างอิงเก็บเฉพาะชั่วคราว ไม่ใส่ลงรีโป); แปลงผลลัพธ์ PNG เป็น JPEG ด้วย Pillow คุณภาพ 88 เพื่อควบคุมขนาด ภาพทั้งหมดเป็นคอนเซปต์รอผู้ใช้เลือกและไม่ได้ถูกนำเข้าเกม

| ไฟล์ | สรุป prompt |
|---|---|
| `docs/concept/set2_ray.jpg` | กระเบนแบนปีกกว้างปลายแหลม ตาสีฟ้าคู่ หางเรียวยาวมีเงี่ยง หลังเทาฟ้าท้องอ่อน; มุมเฉียงบนและด้านข้าง |
| `docs/concept/set2_shark.jpg` | ฉลามลำตัวเพรียว ตาคู่ ครีบหลังและอก เหงือก ปากมีฟัน หางสองแฉก; มุมเฉียงบนและด้านข้าง |
| `docs/concept/set2_eel.jpg` | ปลาไหล/งูทะเลลำตัวยาวไม่มีแขนขา ตาคู่ ลายขวางเขียวเข้มสลับเหลืองหม่น; มุมเฉียงบนและด้านข้าง |
| `docs/concept/set2_whale.jpg` | วาฬลำตัวหนา ตาคู่ ปากกว้าง ครีบอกคู่ หางสองแฉก หลังเทาฟ้าท้องอ่อน; ปรับร่างด้วย Image Generation ให้ปากไม่มีฟันตามโมเดลเกม; มุมเฉียงบนและด้านข้าง |

ทั้งสี่ prompt ใช้ผิวหยาบสมจริง น้ำเขียวฟ้าเข้ม แสงลอดจากด้านบน ไม่มีข้อความ โลโก้ ลายน้ำ UI หรืออุปกรณ์ และให้สร้างตัวละครใหม่โดยไม่คัดลอกจากเกม/แบรนด์อื่น ไฟล์แต่ละภาพมีสองมุมของตัวเดียวกัน ภาพใดผ่านหรือควรปรับให้ผู้ใช้เป็นผู้ตัดสินก่อนเริ่มชุดฉาก

## ชุดที่ 3 — ฉาก 5 ไบโอม

วันสร้าง 2026-11-01 UTC. เครื่องมือ OpenAI Image Generation ใช้ภาพกระเบนชุด 2 ที่ผู้ใช้ผ่านเป็นแนวแสงและโทน และภาพหน้าจอเกมแต่ละไบโอมเป็นแนวจัดพื้นที่และมุมกล้องเท่านั้น (ภาพหน้าจออ้างอิงเก็บชั่วคราว ไม่ใส่รีโป) แปลง PNG เป็น JPEG ด้วย Pillow คุณภาพ 88 ภาพเป็นคอนเซปต์รอผู้ใช้เลือก ยังไม่ได้นำเข้าเกม

ทุก prompt ขอภาพต้นฉบับมุมสูงเฉียงแบบเกมแนวนอน ใต้น้ำโทนเขียวฟ้าเข้มลึกลับ แสงจากด้านบน ไม่มีตัวละคร UI ตัวหนังสือ โลโก้ หรือลายน้ำ และไม่คัดลอกเกมหรือแบรนด์อื่น ภาพเหล่านี้เป็นเพียงตัวอย่าง งบแอสเซ็ตเกมและประสิทธิภาพ iPad ต้องวัดเมื่อมีไฟล์เกมจริง

## ชุดที่ 4 — UI เกมแนวนอน

วันสร้าง 2026-11-01 UTC. เครื่องมือ OpenAI Image Generation ใช้ภาพ `set3_shore.jpg` ที่ผู้ใช้อนุมัติเป็นแนวฉาก ภาพ `set1_sea_eater.jpg` ที่สร้างเองเป็นแนวรูปร่าง และภาพหน้าจอเกมเป็นแนวจัดวาง UI (ภาพหน้าจออ้างอิงเก็บชั่วคราว ไม่ใส่รีโป); ปรับภาพร่างด้วย Image Generation ให้เห็นขาหน้าสองข้างและถอยกล้องให้เห็นพื้นที่เล่นมากขึ้นตามข้อมูลผู้ใช้ล่าสุด แล้วแปลง PNG เป็น JPEG ด้วย Pillow คุณภาพ 88

| ไฟล์ | สรุป prompt |
|---|---|
| `docs/concept/set4_ui.jpg` | หน้าจอ iPad แนวนอนมุมสูงเฉียงใต้ทะเลเขียวฟ้ามืดสมจริง Sea Eater ไม่มีตา ปากกลวง ตัวเป็นปล้อง มีขาหน้าสองข้างและหางครีบ ใหญ่กว่ามอนสเตอร์รอบตัว; แถบ HP/EXP ซ้ายบน มินิแมปขวาบน จอยซ้ายล่าง ปุ่มโจมตี/สกิล/เป้าขวาล่าง และตัวนำทางกลางล่าง เว้นช่องระหว่างปุ่ม ไม่มีตัวหนังสือ โลโก้ หรือลายน้ำ |

ภาพนี้เป็นคอนเซปต์รอผู้ใช้เลือก ยังไม่ได้นำไปใช้ในเกม การจัดวางเป็นภาพประกอบ ต้องทดสอบขนาดปุ่มและประสิทธิภาพบน iPad จริงเมื่อมีการพัฒนาภายหลัง
