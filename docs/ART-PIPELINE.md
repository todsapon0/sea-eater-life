# ART-PIPELINE — ภาพทั้งเกมให้ GPT (เครื่องมือสร้างภาพ) ทำ, โค้ดแค่เอาไปใส่ (ผู้ใช้เลือก 2026-11-01)

เหตุผล: ภาพที่ปั้นด้วยโค้ดเป็นทรงเรขาคณิต สวยไม่ถึงที่ผู้ใช้ต้องการ ผู้ใช้ยืนยันว่า GPT สร้างภาพได้ดีและสร้างได้บ่อย

## สไตล์กลาง (ใช้ซ้ำทุก prompt ให้ภาพเข้าชุดกัน)
การ์ตูนใต้ทะเลสดใส แสงเงานุ่ม สีพาสเทลอิ่ม ขอบมนไม่มีเหลี่ยม ตาใหญ่ น่ารัก แสงลอดน้ำจากด้านบน บรรยากาศแบบเกมมือถือแฟนตาซี (แรงบันดาลใจ: ความสดใสนุ่มนวลแบบเกม RPG การ์ตูน — **ห้ามลอกตัวละคร/ภาพ/ไฟล์ของเกมอื่น**) ไม่มีตัวหนังสือ ไม่มีลายน้ำ ไม่มีโลโก้

## ลำดับ (ทำทีละขั้น ให้ผู้ใช้เลือกก่อนไปขั้นต่อไป)
1. **คอนเซปต์ 3 ใบ** (docs/concept/): ฉาก, ตัวละคร+มอนสเตอร์, หน้าจอ UI → ผู้ใช้เลือกแบบ
2. **ทางที่ 1 — ฉากเป็นภาพวาด** (assets/scene/): ผมเขียนโค้ดวางเป็นท้องฟ้า/ฉากหลังไกล + เท็กเจอร์พื้น
   - `sky_<biome>.jpg` 2048×1024 ไม่มีรอยต่อซ้าย-ขวา (ไล่สีน้ำจากผิวน้ำลงลึก) — biome: shore, kelp, cave, lair, town
   - `floor_<biome>.jpg` 1024×1024 ทำซ้ำต่อกันได้ไร้รอยต่อ (sand/มอส/หิน) มองจากด้านบน
   - `decor_<name>.png` พื้นหลังโปร่งใส 512×512 (ปะการัง สาหร่าย ดอกไม้ทะเล หิน เห็ดเรืองแสง) มุมมองเฉียงเหมือนเกม ผมจะตั้งเป็นแผ่นหันหน้าเข้ากล้อง
3. **ทางที่ 2 — ตัวละคร/มอนสเตอร์เป็นภาพ 2D** (assets/char/): ภาพโปร่งใส 512×512 หนึ่งตัวต่อไฟล์ ท่าเดียวก่อน (ยืน/ว่าย หันข้างเฉียง) ภายหลังค่อยเพิ่มท่ากัด/โดนตี
4. **UI** (assets/ui/): ไอคอนปุ่มสกิล, กรอบหน้าต่าง, แถบเลือด — PNG โปร่งใส

## ข้อกำหนดไฟล์ (สำคัญกับ iPad 8)
- JPG/PNG ขนาดไม่เกินที่ระบุ รวมทุกไฟล์ต้องเบา (เป้าหมายรวม < ~15MB) ตั้งชื่อตามด้านบน ตัวพิมพ์เล็ก ไม่มีเว้นวรรค
- พื้นหลังโปร่งใสต้องโปร่งใสจริง (ไม่ใช่ลายหมากรุกในภาพ)
- ลิขสิทธิ์สะอาด: บันทึกใน docs/ART-LOG.md ว่าแต่ละไฟล์สร้างด้วยเครื่องมืออะไร/วันที่/prompt สรุป
- ไม่ใส่ภาพอ้างอิงของคนอื่นหรือภาพที่ผู้ใช้ส่งมาในรีโป

## การโหลดในเกม (ฝั่ง Claude)
เกมเป็นไฟล์เดียว: จะโหลดภาพด้วย TextureLoader แบบ lazy ต่อแมพ และมี fallback เป็นของเดิมถ้าไฟล์ไม่มี (เกมไม่พังถ้าภาพยังไม่มา) ต้องตรวจว่าโฮสต์ปัจจุบันเสิร์ฟโฟลเดอร์ assets/ ได้ (ดู DEPLOY) ก่อนใช้จริง
